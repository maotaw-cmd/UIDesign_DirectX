# Catalyst

A self-contained Win32 + Direct3D 11 + Direct2D + DirectWrite UI template. It uses no external libraries and keeps the embedded 3D character.

## Open and build

1. Open `Catalyst.sln` in Visual Studio 2022.
2. Select `Release` and `x64`.
3. Build the solution.

The required Windows libraries are already listed in the project file:
`d3d11`, `dxgi`, `d3dcompiler`, `d2d1`, `dwrite`, `user32`, and `gdi32`.

## Project structure

- `src/main.cpp` — small entry point only.
- `src/Core/ProjectCore.hpp` — settings, application state, shared UI widgets, sliders, dropdowns, and colour picker.
- `src/Config/ConfigManager.hpp` — config paths, name validation, save, load, delete, default creation, and config list refresh.
- `src/Config/ConfigUI.hpp` — configuration page drawing and config-page button handling.
- `src/Renderer/DirectXRenderer.hpp` — Direct3D/Direct2D setup, shaders, glow pipeline, and character rendering.
- `src/Renderer/EmbeddedCharacterMesh.inl` — embedded character vertices and indices. Normally do not edit this file.
- `src/UI/VisualsUI.hpp` — Visuals page, popup cards, preview overlays, and settings page. It contains no config persistence or config-page UI.
- `src/App/Application.hpp` — Win32 window creation, mouse/keyboard input, and message handling.

The modules are included by one small `main.cpp`. This keeps the original DirectX state reliable while separating the project into easy-to-find files and avoiding linker complexity for beginners.

## Sound-walk animation

On the Visuals page, the Sound Walk row now has:

- a gear icon directly left of the paint icon;
- animation style: Smooth, Cinematic, Fast, or Minimal;
- speed slider;
- expansion slider;
- line-width slider.

These values are saved and loaded with every named config.

## Sound Walk animation controls

Sound Walk animation is edited only from the gear icon beside **Sound walk** on the Visuals page. The main Settings page intentionally contains no Sound Walk animation controls.


## Sound Walk UI location

The Sound Walk row and its animation popup are implemented only in `src/UI/SoundWalkSettings.hpp`. The main Settings page has no Sound Walk animation controls.
