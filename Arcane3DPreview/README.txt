Arcane3DPreview - Visual Studio 2026 / v145

Open Arcane3DPreview.sln and build x64.

The uploaded Direct2D menu is kept as the main window.
A second Direct3D 11 preview window is created automatically on the right.

Preview:

- box / corner box
- filled box
- name
- health bar
- distance
- weapon
- damage text
- glow
- snapline and skeleton when enabled
